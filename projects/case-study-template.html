03 Transformation Engine: SQL / DAX Logic

[Explain your query architecture: CTEs, Window Functions, or DAX measures used.] 

WITH CustomerOrderTiers AS (
    SELECT 
        customer_id,
        SUM(total_amount) AS lifetime_spend,
        DENSE_RANK() OVER (ORDER BY SUM(total_amount) DESC) AS spend_rank
    FROM orders
    WHERE order_status != 'Cancelled'
    GROUP BY customer_id
)
SELECT * FROM CustomerOrderTiers
WHERE spend_rank <= 10;
